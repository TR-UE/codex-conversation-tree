# 对话树 · 本机 Codex 插件

安装一次，在 Codex 中按需打开对话树。继续使用原生 Codex 聊天，插件提供树形记录、历史分叉、共享记忆版本、剪枝与可选删除原生会话。

## 节点改名、树管理与当前对话优先（0.4.5）

节点详情标题右侧新增“改名”，可保存自定义名称或恢复默认名；分支和整棵树也能改名。名称只改变本地显示，后台同步继续保留它，原始提问与回答不变。

点击顶部“管理对话树”可删除整棵树并停止记录，删除后退出普通列表，可在管理页恢复。检查原生会话状态时只读取已关联会话的元数据；所有来源均已失效的树会从普通列表隐藏，本地记录仍可查看。超时或暂时未加载不会被判定成删除。

从当前对话打开面板时使用返回的完整地址，其中带有该对话的标识。面板优先选择它所属的树，切换查看其他树后可“返回当前对话树”，各面板互不影响。已删除的当前树显示恢复入口，不会跳到另一棵树。旧的固定 localhost 地址没有当前对话信息，请通过当前对话重新打开面板。

## 安装

适用于 macOS 本机 Codex；Linux 的启动脚本也可使用，但桌面插件界面尚未验证。需要 Node.js 22 以上（读取压缩历史需要 Node.js 24）；安装脚本优先寻找 Codex 自带的 Node，无需另行下载依赖。

1. 解压本插件目录，双击其中的 `安装.command`。
2. 安装器会把代码放到桌面 `Codex-Conversation-Tree/plugin/`，把数据放到 `Codex-Conversation-Tree/data/native/`，并合并个人插件目录 `~/.agents/plugins/marketplace.json`。已有对话数据和其他插件条目保留。
3. 重启桌面应用，在插件目录中选择“我的本地工具”，确认“对话树”已安装和启用。
4. 在一个新会话中选择插件“对话树”，发送“打开对话树面板并记录当前对话”。首次设置可使用插件提供的 setup 流程。

安装器同时注册标准 MCP 兼容入口。插件 Skill 还包含一个本机 CLI 入口，因此已有会话没有刷新 MCP 工具时，也可以由 Codex 打开内置浏览器中的面板。原生 MCP Apps 视图仍需在重启后的宿主中单独验证。

## 使用

- “打开对话树面板并记录当前对话”：只关联当前会话，后续提问与可见回答自动记录。
- “查看已经记录的对话树”：查看已有记录，不自动关联其他会话。
- 点击历史节点创建一条新分支，创建后直接打开并继续提问；原路径保留。导入的旧节点没有历史文件快照。
- 选择分支，在“打开分支”旁点击“设为主分支”；已有新提问的分支也可以在提问详情顶部设置。切换后旧主线可剪枝，新主分支及其子分支、共有历史和树根记忆保留。
- 需要保留的结论由你选择纳入树根，保存时保留版本和来源。
- “剪掉分支”默认只隐藏与停止同步，可恢复。
- “同时永久删除原生 Codex 会话”默认关闭，显示完整原生子分支范围（包括未关联到树的分支）并要求确认。删除后原生会话不能恢复，已有本地记录和树根记忆保留。
- 原始会话是原生历史来源，本版只支持剪枝，不支持永久删除它。包含当前主分支的路径也不能整支永久删除，界面会禁用选项并说明原因。

MCP 握手和工具发现不会启动记录后台，实际打开或调用工具时才启动。仅记录显式关联的聊天；不归档二进制附件或隐藏推理，也不上传本机记录。

## 分发

可以分发这份不含个人数据的本地插件目录或 ZIP。每位使用者在自己的电脑上安装，使用自己的 Codex 登录和桌面数据目录。当前不是公共插件目录中的已发布商品；本地 MCP 插件公开上架另有平台资格和审核要求。
