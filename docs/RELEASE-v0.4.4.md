对话树的首个 GitHub 公开测试版。把 Codex 长对话整理成可分叉的路径，并维护用户选定的共享结论。

本版支持自动记录已关联对话、从历史轮次创建原生分支、选择主分支、剪枝恢复和树根记忆版本。新分支可以在同一个原生会话 ID 上继续使用。

下载附件中的 `codex-conversation-tree-0.4.4-macOS.zip`，解压并双击 `安装.command`；重启应用后启用“对话树”，在新对话中通过 `@` 选择插件并发送“打开对话树面板并记录当前对话”。

已验证 macOS 本机安装、33 项单元测试和 10 个 MCP 工具发现。演示使用独立示例数据；安装包不包含私人聊天、共享记忆或登录凭据。附件 `SHA256SUMS` 提供安装包校验值。

这是 macOS 测试版，尚未上架 OpenAI 公共插件目录。原生 MCP Apps 视图的宿主渲染尚未单独验证；当前已验证内置浏览器面板。历史分叉不恢复旧文件状态，原始会话仍不支持永久删除。详见仓库首页的功能边界。
